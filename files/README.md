# My-Class-Track (MCT)

برنامه وب فارسی برای مدیریت گروه درمانی؛ قابل استفاده در موبایل و دارای پشتیبانی آفلاین.

## ساختار پروژه
- `index.html`: پوسته، بارگذاری اسکریپت‌ها و گزارش خطای اولیه
- `css/app.css`: طراحی واکنش‌گرا و تم‌ها
- `js/core.js`: تقویم شمسی، مدل داده، ذخیره‌سازی و ابزارهای پایه
- `js/pages.js`: ساخت صفحات و فرم‌ها
- `js/features.js`: قابلیت‌های کمکی رابط
- `js/app.js`: ناوبری، نقش‌ها، اتصال رویدادها و راه‌اندازی
- `sw.js`: کش نسخه‌بندی‌شده و حالت آفلاین
- `docs/ARCHITECTURE.md`: مرز مسئولیت فایل‌ها و ملاحظات طراحی
- `docs/GUIDE.md`: راهنمای کار و چک‌لیست آزمون دستی
- `docs/REPOSITORY_CATALOG_FA.md`: نقشه مخازن GitHub، تصمیم‌های ادغام و سامان‌دهی

## ترتیب بارگذاری
`core.js → pages.js → features.js → app.js`؛ ترتیب وابستگی‌ها را تغییر ندهید مگر پس از بررسی و آزمون.

## کنترل کیفیت خودکار
GitHub Actions نحو JavaScript، وجود فایل‌های محلی، شناسه‌های تکراری HTML و هماهنگی نسخه کش را بررسی می‌کند. سبز بودن این آزمون‌ها صحت کامل منطق برنامه یا رفتار رابط روی گوشی را تضمین نمی‌کند.

## انتشار و کش
GitHub Pages از شاخه `main` منتشر می‌شود. در هر انتشار، نسخه CSS/JS در `index.html` و `sw.js` باید یکسان باشد تا مرورگر فایل‌های قدیمی را با فایل‌های جدید مخلوط نکند. پیش از پاک‌سازی داده‌های مرورگر، از بخش پشتیبان‌گیری خروجی بگیرید.

**وب‌سایت:** https://majidsb1982.github.io/MCT/

## نصب روی موبایل و استفاده آفلاین

- **اندروید:** صفحهٔ برنامه را در Chrome باز کنید؛ دکمهٔ نصب (⬇) بالای برنامه یا منوی مرورگر را بزنید و «Install app / افزودن به صفحهٔ اصلی» را انتخاب کنید.
- **آیفون و آیپد:** صفحه را در Safari باز کنید، «اشتراک‌گذاری» و سپس «Add to Home Screen / افزودن به صفحهٔ اصلی» را انتخاب کنید.
- برنامه برای ذخیره و مدیریت داده‌ها به حساب کاربری یا سرور اختصاصی نیاز ندارد؛ داده‌ها در فضای محلی مرورگر همان دستگاه نگهداری می‌شوند.
- برای بارگذاری اولیهٔ فایل‌های برنامه لازم است یک‌بار اینترنت در دسترس باشد. پس از آن، بخش‌های کش‌شده می‌توانند آفلاین باز شوند؛ قابلیت‌هایی مانند همگام‌سازی خودکار بین دستگاه‌ها فراهم نیست.
- پیش از پاک‌کردن داده‌های مرورگر یا حذف برنامه، از بخش پشتیبان‌گیری خروجی بگیرید. نصب روی دستگاه دیگر، داده‌های دستگاه قبلی را خودکار منتقل نمی‌کند.

## ویژگی‌های جدید تجربه کاربری (نسخه ۲۶ — بازطراحی UI/UX)

### 🎨 طراحی مدرن و ارگونومی چشم
- سیستم تم تیره/روشن با متغیرهای CSS و سایه‌های لایه‌ای نرم
- تایپوگرافی فارسِ خوانا با فونت وزیرمتنِ میزبانی‌شده محلی (preload + font-display:swap)
- اهداف لمسی حداقل ۴۴px (دکمه‌های وضعیت ۴۸px روی لمسی)
- گذار نرم بین صفحات با View Transitions API و انیمیشن ورود مودال‌ها
- رعایت prefers-reduced-motion برای کاربران حساس به حرکت
- تیکِ بصری ✓ روی وضعیت فعال و هالهٔ پیشنهادِ عمل پرکاربرد در نوبت ۲

### ✋ ارگونومی دست و سرعت عمل
- حفظ جای اسکرول هنگام ثبت وضعیت/پرداخت (دیگر بازگشت به بالای لیست نیست)
- بازخورد لمسی هپتیک روی ثبت حضور، شهریه و ناوبری
- نگه‌داشتن انگشت روی ردیف عضو (موبایل) = انتخاب چندنفره، هم‌ارز راست‌کلیک دسکتاپ
- فیلدهای جستجو با کیبورد موبایل بهینه (type=search و کلید «جستجو»)
- جلوگیری از «کشیدن برای نوسازی» تصادفی هنگام ثبت داده (overscroll-behavior)

### ⌨️ میانبرهای صفحه‌کلید
| میانبر | عملکرد |
|--------|---------|
| `Ctrl+K` | پالت دستورات (جستجوی سریع هر عملیات) |
| `Ctrl+B` | پشتیبان‌گیری فوری |
| `Ctrl+/` | فوکوس روی جستجوی لیست |
| `H / A / F / M / W / T / S / O / R` | رفتن به خانه، حضور، شهریه، اعضا، تکالیف، وظایف، تنظیمات، بخش‌ها، گزارش‌ها |
| `E` | شروع نوبت ۲ پشت در |
| `N` | عضو جدید |
| `Esc` | بستن پنجره‌های شناور |

### 📱 PWA 2026
- میان‌برهای آیکون نصب‌شده (حضور، شهریه، اعضا، تکالیف) و باز شدن با `?page=…`
- نشان تعداد کارهای معلق روی آیکون اپ (Badging API) با نبض بصری در ناوبری
- `launch_handler` برای متمرکز نگه‌داشتن پنجرهٔ اپ

### 📊 داشبورد صفحه خانه
- کارت‌های آمار رنگ‌دار برای حضور، شهریه، تکالیف و وظایف
- شمارنده معکوس تا کلاس بعدی
- خوش‌آمد شخصی‌سازی‌شده با نام کاربر فعلی

### 🔍 جستجوی هوشمند
- جستجوی با تأخیر (debounce) برای عملکرد بهتر در لیست‌های بلند
- حالت خالی با پیام دوستانه وقتی نتیجه‌ای یافت نمی‌شود

### 📶 وضعیت اتصال
- نوار آفلاین/آنلاین در بالای صفحه
- ادامهٔ کار بدون اینترنت؛ داده‌ها روی دستگاه ذخیره می‌شوند
