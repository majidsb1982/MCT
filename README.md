# My-Class-Track v9 — گردش‌کار گروه درمانی

## حامی کیست؟
اعضای قدیمی که قبلاً مسئول حضور/شهریه/تکالیف بوده‌اند و الان:
- پشتیبان مسئولان جدید هستند
- رابط بین اعضا و درمانگر (دکتر) هستند
- گیرنده گزارش‌های هر نوبت‌اند

## نوبت حضور
1. **نوبت ۱** — تماس قبلی (روز یا چند ساعت قبل)
2. **نوبت ۲** — پشت در کلاس (~۳۰ دقیقه قبل) + چک‌لیست اعلام به درمانگر ۱۵/۸/۵/۳

## شهریه
مهلت پیش‌فرض: **یک روز قبل از کلاس** — فیش در واتساپ؛ وضعیت و اکسل در اپ.

## دوره
تنظیمات → یا از کارت دوره در خانه: مسئولان حضور / شهریه / تکالیف هر دوره با نظر درمانگر.
