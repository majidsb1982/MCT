# My-Class-Track (MCT) v21

دستیار آفلاین گروه درمانی — PWA فارسی (RTL)

## ساختار سه‌لایه JS

| فایل | نقش |
|------|-----|
| `js/core.js` | تاریخ شمسی، Store، toast/modal |
| `js/pages.js` | صفحات UI (خانه، حضور، شهریه، …) |
| `js/app.js` | روتینگ، نقش‌ها، قابلیت‌ها، شروع |

```
index.html
css/app.css
js/core.js → pages.js → app.js
sw.js · manifest.webmanifest · icon.svg
GUIDE.html · GUIDE.md
```

## ناوبری موبایل

- **خانه** — کاشی دسترسی سریع
- **حضور / شهریه / اعضا** — کار اصلی
- **بیشتر** — تکالیف، گزارش‌ها، تنظیمات، راهنما
- نشان قرمز = کارهای باز

## اجرا

```bash
python -m http.server 8080
```

یا GitHub Pages: `https://majidsb1982.github.io/MCT/`

## گردش کار

1. نوبت ۱ تماس قبلی  
2. شهریه تا یک روز قبل  
3. نوبت ۲ پشت در + ۱۵/۸/۵/۳  
4. گزارش به حامی‌ها  
5. پشتیبان هفتگی  

## حریم خصوصی

یادداشت محرمانه در گزارش حامی نمی‌آید. داده فقط روی دستگاه است.
