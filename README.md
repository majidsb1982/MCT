# My-Class-Track (MCT) — نسخه ۵

دستیار حرفه‌ای کلاس برای معلمان و مدرسان.

ثبت **حضور**، **شهریه**، **اعضا** و **تکالیف** — کاملاً آفلاین، بدون سرور.

🌐 نسخهٔ زنده: [majidsb1982.github.io/MCT](https://majidsb1982.github.io/MCT/)

## ویژگی‌ها

| بخش | قابلیت‌ها |
|-----|-----------|
| **حضور** | دو نوبت (تماس قبلی + ثبت ورود)، تایمر جلسه، هشدار، گزارش متنی و چاپ/PDF |
| **شهریه** | وضعیت پرداخت، پیگیری، یادداشت، گزارش |
| **اعضا** | چند شماره، عکس فشرده، یادداشت صوتی، نقش، گروه، تولد |
| **تکالیف** | متن + صدا، تاریخ شمسی |
| **تنظیمات** | تم روشن/تیره، رنگ، اندازه متن، نام کلاس، گروه‌ها، پشتیبان |
| **داده** | ذخیره‌سازی محلی، پشتیبان JSON با تاریخ، CSV، پاکسازی جلسات قدیمی |

## نصب و اجرا

### GitHub Pages
همین ریپو را به عنوان Pages از شاخه `main` فعال کنید.

### محلی
```bash
npx serve .
# یا
python3 -m http.server 8080
```

سپس در مرورگر باز کنید. برای نصب به‌عنوان اپ، از منوی مرورگر «Add to Home Screen» را بزنید.

## پشتیبان‌گیری

از **تنظیمات → پشتیبان** فایل JSON بگیرید. نام فایل شامل تاریخ شمسی است.

> ⚠️ داده‌ها فقط داخل مرورگر همان دستگاه ذخیره می‌شوند. قبل از پاک کردن کش یا تعویض گوشی حتماً پشتیبان بگیرید.

## ساختار فایل‌ها

```
index.html              # اپ کامل (HTML + CSS + JS)
manifest.webmanifest    # PWA
sw.js                   # Service Worker
icon.svg                # آیکون
README.md
```
