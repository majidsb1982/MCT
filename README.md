# My-Class-Track (MCT)

اپلیکیشن وب فارسی برای مدیریت کارهای یک گروه درمانی: اعضا، پیگیری حضور در دو نوبت، شهریه، تکالیف، گزارش حامی‌ها و یادآورهای روز کلاس.

## شروع سریع

این پروژه بدون فرایند build و بدون وابستگی npm اجرا می‌شود:

1. مخزن را دریافت کنید یا فایل ZIP آن را دانلود کنید.
2. برای پشتیبانی کامل از Service Worker و حالت آفلاین، فایل‌ها را روی GitHub Pages یا یک وب‌سرور محلی/HTTPS اجرا کنید. بازکردن مستقیم `index.html` با `file://` برای نصب آفلاین کافی نیست.
3. برنامه را باز کنید و ابتدا از بخش تنظیمات، کلاس و کاربران را بررسی کنید.
4. پیش از وارد کردن اطلاعات واقعی، یک نسخه پشتیبان آزمایشی تهیه و بازیابی آن را بررسی کنید.

## ساختار پروژه

- `index.html` — پوسته و نقطه ورود برنامه
- `css/app.css` — استایل‌ها
- `js/core.js` — تقویم شمسی، ذخیره‌سازی و ابزارهای پایه
- `js/pages.js` — صفحات و رابط کاربری
- `js/features.js` — قابلیت‌های تکمیلی
- `js/app.js` — گردش کار، دسترسی‌ها و راه‌اندازی برنامه
- `sw.js` — cache و پشتیبانی آفلاین
- `manifest.webmanifest` — مشخصات نصب وب‌اپ
- `docs/GUIDE.md` و `docs/GUIDE.html` — راهنمای کاربری

## ذخیره‌سازی و همگام‌سازی

در نسخه فعلی، داده‌های برنامه در فضای ذخیره‌سازی مرورگر همان دستگاه نگهداری می‌شوند. همگام‌سازی کدها در GitHub فقط فایل‌های پروژه را همگام می‌کند و **اطلاعات اعضا و جلسات را بین دستگاه‌ها همگام نمی‌کند**. برای جابه‌جایی داده از پشتیبان‌گیری و بازیابی داخل برنامه استفاده کنید.

برای همگام‌سازی زنده و چنددستگاهی، به یک backend امن با ورود واقعی، کنترل دسترسی سمت سرور، همگام‌سازی تعارض‌ها و پشتیبان‌گیری نیاز است. به‌دلیل حساس بودن اطلاعات گروه درمانی، قرار دادن اطلاعات واقعی اعضا در GitHub یا داخل فایل‌های مخزن ممنوع است.

## توسعه و کنترل کیفیت

با هر push یا pull request، گردش کار GitHub Actions موارد زیر را بررسی می‌کند:
- نحو JavaScript فایل‌های اصلی
- وجود فایل‌های محلی ارجاع‌شده در HTML
- وجود فایل‌های پوسته آفلاین ارجاع‌شده در Service Worker

این کنترل‌ها خطاهای رایج ساختاری را پیدا می‌کنند، اما جایگزین آزمون دستی همه گردش‌کارها نیستند.

## حریم خصوصی و امنیت

- از رمزهای پیش‌فرض استفاده نکنید و اطلاعات واقعی را در نسخه آزمایشی وارد نکنید.
- PINهای داخل این نسخه، احراز هویت امن سمت سرور محسوب نمی‌شوند.
- پشتیبان JSON می‌تواند شامل اطلاعات حساس باشد؛ آن را فقط در محل امن نگه دارید.
- جزئیات آسیب‌پذیری را عمومی نکنید؛ ابتدا از طریق بخش Security مخزن گزارش دهید.
