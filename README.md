# My-Class-Track (MCT) — نسخه ۶ هوشمند

دستیار کلاس با قابلیت‌های مدرن: بینش هوشمند، گفتار به متن، اعلان، نقشه حرارتی، خروجی تقویم و اشتراک QR.

🌐 [majidsb1982.github.io/MCT](https://majidsb1982.github.io/MCT/)

## نسخه ۶ — نوآوری‌ها

### ظاهری (UI)
- افکت شیشه‌ای (Glassmorphism)
- انیمیشن‌های نرم
- حلقه پیشرفت SVG و Sparkline
- دکمه شناور ✨ بینش
- پشتیبانی prefers-reduced-motion

### ساختاری و هوشمند
- **بینش هوشمند:** میانگین حضور، روند، بیشترین غیبت، نرخ پرداخت
- **نقشه حرارتی حضور** (۴ هفته)
- **گفتار به متن** (Web Speech API — فارسی)
- **اعلان کلاس** ۱۵ دقیقه قبل
- **خروجی تقویم ICS**
- **اشتراک کلاس + QR**
- گروه‌بندی، چاپ PDF، پشتیبان، PWA

## نصب

فایل‌های `MCT-v6.zip` را روی GitHub Pages قرار دهید یا:

```bash
npx serve .
```

## حریم خصوصی

داده‌ها محلی است. تشخیص گفتار توسط موتور مرورگر انجام می‌شود.
