# My-Class-Track (MCT)

دستیار آفلاین گروه درمانی — PWA فارسی (RTL)

**نسخه جاری: ۱۸ (پایدار)**

## چه کار می‌کند؟

مدیریت کلاس گروهی با تمرکز روی:

| نقش | کار |
|-----|-----|
| مسئول حضور | نوبت ۱ (قبل از کلاس) و نوبت ۲ (پشت در) |
| مسئول شهریه | پیگیری واریز تا یک روز قبل + گزارش |
| حامی | دریافت گزارش بدون جزئیات محرمانه |
| درمانگر | یادآور زمان ۱۵ / ۸ / ۵ / ۳ دقیقه |

همه داده روی دستگاه ذخیره می‌شود (`localStorage`) — بدون سرور و بدون حساب ابری اجباری.

## فایل‌های اصلی

```
index.html          اپ کامل (HTML + CSS + JS)
sw.js               Service Worker (آفلاین)
manifest.webmanifest  نصب به‌صورت اپ
icon.svg            آیکون
GUIDE.html          راهنمای تصویری
GUIDE.md            راهنمای متنی
```

## اجرا (محلی)

به‌خاطر Service Worker و PWA، ترجیحاً با یک سرور ساده باز کنید:

```bash
# پایتون
python -m http.server 8080

# یا Node
npx --yes serve -p 8080
```

سپس: `http://localhost:8080`

روی موبایل: همین آدرس در شبکه محلی، یا استقرار روی GitHub Pages.

## استقرار روی GitHub Pages

1. Settings → Pages  
2. Source: **Deploy from a branch**  
3. Branch: `main` / folder: `/ (root)`  
4. ذخیره کنید  

آدرس تقریبی:

`https://majidsb1982.github.io/MCT/`

بعد از هر به‌روزرسانی روی گوشی **Hard Refresh** یا یک‌بار کش را پاک کنید تا `mct-v18` لود شود.

## گردش کار پیشنهادی هر جلسه

1. نوبت ۱ — تماس‌های قبلی  
2. پیگیری شهریه  
3. نوبت ۲ پشت در + چک‌لیست درمانگر  
4. گزارش به حامی‌ها از «مرکز ارتباطات»  
5. پشتیبان هفتگی از تنظیمات  

## حریم خصوصی

- یادداشت محرمانه عضو در گزارش حامی نمی‌آید  
- حالت حریم خصوصی و ورود با PIN اختیاری است  
- بک‌آپ JSON را فقط برای افراد مورد اعتماد بفرستید  

## توسعه

تغییرات را روی شاخه جدا بزنید، تست کنید، بعد به `main` ادغام کنید.  
نسخه‌های آزمایشی را به‌صورت ZIP در Releases بگذارید — نه در ریشه ریپو.

## مجوز

برای استفاده شخصی/گروهی خودتان آزاد است. قبل از استفاده بالینی با درمانگر هماهنگ کنید.
