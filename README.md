# My-Class-Track (MCT)

برنامه وب فارسی برای مدیریت گروه درمانی؛ قابل استفاده در موبایل و دارای پشتیبانی آفلاین.

## ساختار پروژه
- `index.html`: پوسته، بارگذاری اسکریپت‌ها و گزارش خطای اولیه
- `css/app.css`: طراحی واکنش‌گرا و تم‌ها
- `js/core.js`: تقویم شمسی، مدل داده، ذخیره‌سازی و ابزارهای پایه
- `js/pages.js`: ساخت صفحات و فرم‌ها
- `js/features.js`: قابلیت‌های کمکی رابط
- `js/app.js`: ناوبری، نقش‌ها، اتصال رویدادها و راه‌اندازی
- `sw.js`: کش نسخه‌بندی‌شده و حالت آفلاین
- `docs/ARCHITECTURE.md`: مرز مسئولیت فایل‌ها و ملاحظات طراحی
- `docs/GUIDE.md`: راهنمای کار و چک‌لیست آزمون دستی
- `docs/REPOSITORY_CATALOG_FA.md`: نقشه مخازن GitHub، تصمیم‌های ادغام و سامان‌دهی

## ترتیب بارگذاری
`core.js → pages.js → features.js → app.js`؛ ترتیب وابستگی‌ها را تغییر ندهید مگر پس از بررسی و آزمون.

## کنترل کیفیت خودکار
GitHub Actions نحو JavaScript، وجود فایل‌های محلی، شناسه‌های تکراری HTML و هماهنگی نسخه کش را بررسی می‌کند. سبز بودن این آزمون‌ها صحت کامل منطق برنامه یا رفتار رابط روی گوشی را تضمین نمی‌کند.

## انتشار و کش
GitHub Pages از شاخه `main` منتشر می‌شود. در هر انتشار، نسخه CSS/JS در `index.html` و `sw.js` باید یکسان باشد تا مرورگر فایل‌های قدیمی را با فایل‌های جدید مخلوط نکند. پیش از پاک‌سازی داده‌های مرورگر، از بخش پشتیبان‌گیری خروجی بگیرید.
